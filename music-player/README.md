# Side A — Music Player

A responsive playlist player with play/pause, previous/next, shuffle, repeat, autoplay-on-track-end, a seek bar, and volume control.

## Run it

Open `index.html` in a modern browser with an internet connection. The three example audio files are served from SoundHelix; the player reports an error if a sample cannot be reached.

## Learn the code

- `index.html` provides the playlist, player controls, and accessible labels.
- `styles.css` creates the responsive player layout and CSS-only cover art.
- `script.js` contains the track list and handles audio events, the seek bar, volume, and playback buttons.

Try changing a track title in `script.js`, then click the matching track in the playlist. For your own submission, use audio you have permission to share, update the `tracks` array with its URLs and real credits, and adjust the visible playlist text in `index.html` to match.
